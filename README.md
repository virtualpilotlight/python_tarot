# python_tarot
some python scripts for tarot card readings
this is a terminal app for tarot cards written in python
Current functionality 3 card draw and playing card to tarot conversion

pre-req:
a terminal that can run python3, might I suggest bash or zsh. Personally I always test python scripts in a multipass instance but I'm sure wsl on windows works fine too. 
have python3 installed something like "sudo apt install python3" without the quotes probs
clone the repo from github
run the command python3 python_tarot.py from the folder that the repo is cloned to
a general want to do this, basically if you don't like tarot cards or something this aplet isn't for you.
